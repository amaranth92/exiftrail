# ExifTrail 기능 설명

## 한 줄 설명

사진에 남은 촬영일시와 GPS 위치 정보를 시간순으로 연결해, 여행 이동 경로가 지도 위에서 움직이는 영상으로 보이게 하는 Android 앱입니다.

## 짧은 설명

Google Maps Timeline을 사용하지 않는 사람도 여행 사진으로 이동 경로를 만들 수 있도록 만든 앱입니다. 사진 접근 권한을 허용하고 기간을 지정하면, 해당 기간의 사진에서 사용할 수 있는 EXIF 날짜와 GPS 정보를 분석해 경로 영상을 준비합니다. 준비가 끝난 뒤 지도를 미리 보고 영상을 저장할 수 있습니다.

## 사용자 흐름

1. `From`과 `To` 날짜를 선택합니다.
2. `Allow photos and create video`를 누릅니다.
3. 사진 접근 권한을 허용합니다.
4. 선택한 기간의 사진에서 촬영일시와 GPS EXIF 정보를 분석합니다.
5. 지도 위에서 시간순으로 이어지는 이동 경로를 확인합니다.
6. 원하면 `Save video`로 영상을 저장합니다.

## 정확한 표현

### 이렇게 말하기

> Google Maps Timeline 없이, 사진에 남은 GPS EXIF로 여행 경로 영상을 만들어보세요.

> 사진 접근 권한을 허용하고 기간을 고르면, 위치 정보가 있는 사진을 시간순으로 연결해 지도 위 이동 영상으로 보여줍니다.

### 이렇게 말하지 않기

- 권한 없이 사진을 자동 수집합니다.
- GPS가 없는 사진도 정확한 위치를 복원합니다.
- 모든 사진의 위치를 알아냅니다.
- 사진을 서버에 절대 업로드하지 않습니다.

마지막 표현은 현재 공개 문서에서 처리 방식과 네트워크 정책을 별도로 확정하지 않았으므로 사용하지 않습니다.
