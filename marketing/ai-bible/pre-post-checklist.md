# Pre-Post Checklist

## 제품 확인

- [ ] 공개할 APK 또는 다운로드 링크가 실제로 동작합니다.
- [ ] 게시 시점의 지원 범위를 `Android only`로 표시했습니다.
- [ ] 무료 사용 가능 여부와 오픈소스 상태를 README와 게시물에서 동일하게 표현했습니다.
- [ ] `From`과 `To` 날짜 선택 흐름을 새로 설치한 앱에서 확인했습니다.
- [ ] 사진 접근 권한을 허용해야 분석이 시작된다는 점을 설명했습니다.
- [ ] 위치 정보가 없는 사진은 경로에 포함되지 않을 수 있다고 안내했습니다.
- [ ] 지도 미리보기와 저장된 영상의 경로가 일치하는지 확인했습니다.

## 개인정보 표현

- [ ] `권한 없이 사진을 읽는다`는 표현이 없습니다.
- [ ] `모든 사진을 자동으로 분석한다`고 단정하지 않았습니다.
- [ ] 서버 전송, 저장, 삭제에 대한 확인되지 않은 보안 약속을 넣지 않았습니다.
- [ ] 화면 녹화와 스크린샷에 개인 사진, 주소, 얼굴, 계정 정보가 노출되지 않았습니다.
- [ ] 테스트용 사진을 공개 게시물에 포함할 경우 공개 권한을 확인했습니다.

## 게시물 품질

- [ ] 첫 2초 안에 앱이 무엇을 하는지 보입니다.
- [ ] 세로형 미디어에서 자막과 경로가 잘리지 않습니다.
- [ ] 캡션의 링크가 실제 공개 링크로 교체되었습니다.
- [ ] 한국어·영문 캡션 중 계정의 게시 언어에 맞는 문안을 선택했습니다.
- [ ] 해시태그를 8~12개로 정리했습니다.
- [ ] Instagram과 Threads에 같은 문구를 그대로 복사하지 않고 플랫폼에 맞게 줄였습니다.

## 게시 직전 승인

- [ ] 개발 완료 전에는 게시하지 않습니다.
- [ ] 최종 APK, 미디어, 캡션을 직접 검토했습니다.
- [ ] 게시할 계정이 `ai__bible`인지 확인했습니다.
- [ ] 예약 게시 또는 자동 업로드가 설정되어 있지 않습니다.
