# ai__bible ExifTrail 사전 공개 패키지

Instagram과 Threads 계정 `ai__bible`에서 ExifTrail을 소개하기 위한 게시 전 초안입니다.

## 핵심 사실

- 무료로 사용할 수 있는 Android 앱입니다.
- 현재 Android 버전만 제공합니다.
- 사용자가 사진 접근 권한을 허용하면, 기기 사진의 촬영일시와 GPS EXIF 정보를 읽어 시간순 이동 경로를 만듭니다.
- Google Maps Timeline을 허용하지 않아도 사진에 남아 있는 EXIF 위치 정보를 이용할 수 있습니다.
- 사진 접근 권한을 허용하지 않으면 사진을 분석하거나 영상을 만들 수 없습니다.
- 위치 정보가 없는 사진은 경로 점으로 사용할 수 없습니다.
