ExifTrail turns GPS-tagged travel photos into a shareable 9:16 route video.
It reads capture time and GPS metadata locally, animates the journey on a map,
and exports the result for Shorts, Reels, TikTok, or any other video feed.

No account is required. Your photos stay on your device by default.

Start with the hosted web demo, or install the Android APK directly from this
repository.

## What you need

Use JPG, JPEG, HEIC, or HEIF photos that contain GPS coordinates. Photos
without GPS are reported and skipped. The sample route includes one photo
without GPS so you can see that handling before using your own library.
